# Investigating the Autosomal Recessive Inheritance Pattern of MLC1 Gene Mutations in Non-Syndromic Intellectual Disability Patients
## 🧬 Project Overview
This repository hosts the data structure frameworks and project documentation for my Master of Science (MS) thesis. The research focuses on identifying and analyzing the genetic variants of the *MLC1* gene in clinical patient cohorts presenting with non-syndromic intellectual disabilities.
## 🔬 Core Methodology & Specializations
* **Genomic Analysis:** Pedigree construction, family lineage mapping, and tracking autosomal recessive inheritance pathways.
* **Clinical Data Handling:** Managing variant databases, curating clinical phenotypes, and preparing structured scientific insights.
* **Data Visualization:** Developing interactive dashboards using analytical tools to cleanly display mutation distribution metrics.
