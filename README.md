# Investigating the Autosomal Recessive Inheritance Pattern of MLC1 Gene Mutations in Non-Syndromic Intellectual Disability Patients

## 🧬 Project Overview & Molecular Strategy
This repository hosts the structural data curation frameworks, research abstracts, and academic documentation for my Master of Science (MS) thesis completed at Lahore College for Women University. 

The investigation focused on untangling the complex genetic architecture within two consanguineous Pakistani families (PKID0139 and PKID0140) presenting with non-syndromic intellectual disabilities. Following genomic DNA isolation and PCR optimization, targeted Sanger sequencing was executed to profile coding region variations. 

## 📊 Core Research Finding & Curation Workflow
* **The Mutation Screening Result:** Sequence alignment against the Ensembl human reference genome via NCBI BLAST confirmed the **absence of pathogenic variations within coding exon 3** of the *MLC1* gene across all affected cohorts. 
* **The Informatics Pivot:** This negative finding systematically narrowed down the candidate mutation space, shifting the project focus toward multi-genic variant filtering, structural dataset curation, and mapping family pedigree lineages to identify alternative candidate loci.

## 🔬 Computational Methodology & Technical Skills
* **In Silico Curation:** Sequence parsing, database cross-referencing, and local alignment using NCBI BLAST, Ensembl Genome Browser, and Chromas chromatogram assembly tools.
* **Lineage Mapping:** Designing digital multi-generational family pedigree charts to model autosomal recessive segregation pathways.
* **Data Visualization:** Translating complex metrics into clear visual insights. Experienced in creating interactive analytics dashboards to communicate distribution trends.
